# Chat App

A modern, full-stack real-time chat application enabling seamless communication between users. Built with scalability, security, and user experience in mind.

## 🚀 Features

- **Instant Messaging:** Real-time, bi-directional chat powered by WebSockets.
- **User Authentication:** Secure registration and login with session management.
- **Responsive Design:** Optimized for desktop and mobile devices.
- **Message History:** Persistent chat history for all users.
- **Online Presence:** See who is online in real time.
- **Typing Indicators:** Know when someone is typing.
- **Notifications:** In-app alerts for new messages.

## 🛠️ Tech Stack

- **Frontend:** React, Material-UI, 
- **Backend:** Node.js, Express.js
- **Real-Time:** Socket.io
- **Database:**  MongoDB
- **Authentication:** JWT or session-based (specify as implemented)

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16+ recommended)
- npm (comes with Node.js)

### Installation

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/chat-app.git
    cd chat-app
    ```
2. **Install dependencies:**
    ```bash
    npm install
    ```

### Configuration

- Copy `.env.example` to `.env` and update environment variables as needed.

### Running the App

1. **Start the backend server:**
    ```bash
    npm run dev
    ```
2. **Start the frontend client:**
    ```bash
    npm run dev
    ```

Open [http://localhost:5173] in your browser.
